## How I Think About Engineering

### Systems Before Software

The hardest part of software projects is often not writing the code—it is understanding the system the code belongs to.

I start with the operational problem, constraints, integrations, risks, and desired business outcome. Then I determine what combination of software, AI, automation, infrastructure, and internal tooling actually solves it.
